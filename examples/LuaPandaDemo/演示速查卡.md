## 手动演示 6 步

1. IDEA 打开 `LuaPandaDemo` → 选 **LuaPanda Demo (Server)** → 🐞 Debug（监听 8818）。
2. 打开 demo.lua，`Ctrl+F` 搜 `BP-A` → `Ctrl+F8` 打行断点（128 行）。
3. 运行 `run_demo.bat` → 连接后立刻停在 128 行。
4. Variables 面板展开 `skill` / `unit`；Frames 面板看 3 层调用。
5. `Alt+F8` 求值：`hero.crit * 100`。
6. `F9` 放行 → 后续在 145（条件断点只停 i==5）、165、176、195、208、218 逐点演示；结束点 ■ Stop。

## 单步与快捷键

| 操作 | 按键 |
|------|------|
| 打/取消行断点 | `Ctrl+F8` |
| 条件断点编辑 | 断点红点右键 → Condition 填 `i == 5` |
| 日志断点 | 断点红点右键 → 勾选 Evaluate and log，填 `"第 {i} 次攻击 -> {damage}"` |
| Step Over / Into / Out | `F8` / `F7` / `Shift+F8` |
| Resume | `F9` |
| 表达式求值 | `Alt+F8` |
| 停止 | `Ctrl+F2` |
